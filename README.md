# KODURAMA ORU PROJECT

> An intelligent ERP enhancement that combines **Computer Vision**, **Machine Learning**, **Artificial Intelligence**, and **Placement Assistance** to help students improve academic performance, develop technical skills, and become placement-ready.

---

## 📖 Overview

The **AI-Powered Smart Attendance and Personalized Student Support System** is a next-generation educational platform designed to provide a unified experience for students and faculty.

Unlike traditional ERP systems that only display attendance and marks, this platform analyzes student data and delivers personalized insights, learning recommendations, placement guidance, and AI-driven support.

The system integrates:

* 🎯 Smart Face Recognition Attendance
* 📊 Academic Performance Analytics
* 💻 Coding Profile Tracking
* 🤖 AI Placement Assistant
* 📈 Personalized Recommendations
* 📄 Resume & Placement Readiness Monitoring

# 🔄 System Workflow

1. Student logs into the platform.
2. Attendance is recorded using face recognition.
3. Academic and attendance records are synchronized.
4. Coding activity is collected from supported platforms.
5. AI analyzes student progress.
6. Skill gaps are identified.
7. Personalized recommendations are generated.
8. Placement readiness is evaluated.
9. Faculty receives insights for early intervention.
